# 國分Web製作所 — 1ページ制作デモ集

業種ごとに写真・文字・余白・情報の順番を作り分けた、4つの架空の事業者の制作デモです。トップページの制作実績直後にある `#demos` から閲覧できます。

| 業種 | デモ | ページ | 設計のポイント |
| --- | --- | --- | --- |
| 設備会社 | 澄川設備 | `equipment/` | 対応範囲、施工内容、見積もり前の確認事項 |
| 不動産会社 | 間と庭不動産 | `real-estate/` | 住まいの雰囲気、比較項目、現地で確かめること |
| 行政書士事務所 | 紙と道 行政書士事務所 | `legal/` | 相続・建設業許可の相談別の入口、専門用語の注釈、業務範囲と準備 |
| 税理士事務所 | 青庭会計室 | `tax/` | 事業の段階に合う支援、役割分担、費用が変わる要因 |

各ページはHTMLとCSSを中心に構成し、FAQなどは標準の `details` 要素で操作できます。制作相談のリンクは國分Web製作所の相談ページへ移動します。`?demo=` の指定がある場合は、見ていたデモを伝える相談文が表示されます。デモ事業者への問い合わせや、個人情報を送信するフォームは設置していません。

## 写真とプレビュー

- 掲載写真は各ページ4点、全16点です。この制作のために組み込みの `image_gen` で生成した架空の風景・人物・作業場面です。外部サイトの写真は使用していません。
- 実在の企業ロゴ、既存写真、著名な建物、特定の作家の作風を指定せずに生成しています。
- 各デモの `images/*.webp` が配信用の最終画像です。生成指示の内容、元の生成ファイル名、寸法、SHA-256は各フォルダの `sources.json` に保存しています。
- 配信用画像には縮小とWebP形式への変換のみを行っています。生成された元画像は画像生成の出力先に保持しています。
- トップの `assets/img/demo-*.webp` は、実装したデモページをブラウザで表示して作成したプレビューです。

## 表示上の区別

事業者・物件・施工事例・サービス設定は架空であることを、ページ上部と各例・フッターに記載しています。実在の実績や資格番号、所在地、電話番号、利用者の声を捏造していません。デモページは `noindex,follow` とし、実在の事業者の検索結果と混同されない構成にしています。

## 行政書士デモの情報設計

2026年9月26日に、業務テーマを相続関係と建設業許可に変更しました。建設業の写真を1点新たに生成し、旧画像は生成記録とともに保持しています。確認した一次資料、用語の扱い、プレインランゲージと認知負荷に関する設計意図は [調査・設計記録](legal/content-design.md) に記載しています。
