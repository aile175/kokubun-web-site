# 國分Web製作所 — 制作デモ集

業種ごとに写真・文字・余白・情報の順番を作り分けた、4つの架空の事業者の制作デモです（1ページ構成3種・3ページ構成1種）。トップページの制作実績直後にある `#demos` から閲覧できます。

| 業種 | デモ | ページ | 設計のポイント |
| --- | --- | --- | --- |
| 設備会社 | 澄川設備 | `equipment/` | 対応範囲、施工内容、見積もり前の確認事項 |
| 不動産会社 | 間と庭不動産 | `real-estate/` | 住まいの雰囲気、比較項目、現地で確かめること |
| 行政書士事務所 | 紙と道 行政書士事務所 | `legal/` | 相続・建設業許可の相談別の入口、専門用語の注釈、業務範囲と準備 |
| 税理士事務所 | 数と言 税理士事務所 | `tax/`（3ページ：トップ `index.html` / サービスと料金 `services.html` / はじめての方へ `consult.html`） | 状況から選ぶ入口、ソフト・AIと税理士の分担、期限の見える化、年間の合計で比べる料金と試算、専門用語の注釈と用語集、相談メモ |

各ページはHTMLとCSSを中心に構成し、FAQなどは標準の `details` 要素で操作できます。税理士デモは、フレームワークを使わないHTML・CSS・JavaScriptで、動きと相談準備のツールを実装しています。制作相談のリンクは國分Web製作所の相談ページへ移動します。`?demo=` の指定がある場合は、見ていたデモを伝える相談文が表示されます。デモ事業者への問い合わせや、個人情報を送信するフォームは設置していません。

## 写真とプレビュー

- 生成した写真は各デモ4点、全16点です。税理士デモは写真を1点（相談室）だけ使い、ほかの3点はページから外しています（生成記録は `tax/sources.json` に保持）。この制作のために組み込みの `image_gen` で生成した架空の風景・人物・作業場面です。外部サイトの写真は使用していません。
- 実在の企業ロゴ、既存写真、著名な建物、特定の作家の作風を指定せずに生成しています。
- 各デモの `images/*.webp` が配信用の最終画像です。生成指示の内容、元の生成ファイル名、寸法、SHA-256は各フォルダの `sources.json` に保存しています。
- 配信用画像には縮小とWebP形式への変換のみを行っています。生成された元画像は画像生成の出力先に保持しています。
- トップの `assets/img/demo-*.webp` は、実装したデモページをブラウザで表示して作成したプレビューです。

## 表示上の区別

事業者・物件・施工事例・サービス設定は架空であることを、ページ上部と各例・フッターに記載しています。実在の実績や資格番号、所在地、電話番号、利用者の声を捏造していません。デモページは `noindex,follow` とし、実在の事業者の検索結果と混同されない構成にしています。

## 行政書士デモの情報設計

2026年9月26日に、業務テーマを相続関係と建設業許可に変更しました。建設業の写真を1点新たに生成し、旧画像は生成記録とともに保持しています。確認した一次資料、用語の扱い、プレインランゲージと認知負荷に関する設計意図は [調査・設計記録](legal/content-design.md) に記載しています。

## 税理士デモの情報設計

2026年9月29日に全面的に作り直しました（v2）。「入力はAIに。判断は、税理士と。」を事務所の立場として、ページ名を「サービスと料金」「はじめての方へ」という分かりやすい言葉にし、料金はすべて表示例（架空）として載せています。配色は白地に納戸色（青緑）の1色だけを使い、青緑は「判断・期限・次にすること」だけに使います（2026年10月7日に、黒と朱の組み合わせから変更）。確認した一次資料、専門用語の注釈ルール、プレインランゲージ・情報アーキテクチャ・サービスデザイン・行動経済学・認知科学の適用箇所は [調査・設計記録](tax/content-design.md) に記載しています。各ページ上部の「設計の根拠を表示」から、画面上でも設計の根拠を確認できます。
